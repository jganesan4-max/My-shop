💡 "📤 Backup" தட்டி ஒரு ஃபைலை பதிவிறக்கம் செய்து, அதை Google Drive அல்லது WhatsApp (Message Yourself) மூலம் பாதுகாப்பாக வைக்கவும். மொபைல் தொலைந்தாலும், மாறினாலும், "📥 Restore" மூலம் அதே ஃபைலை தேர்ந்தெடுத்து பொருட்கள் மற்றும் விற்பனை தகவல்கள் முழுவதையும் மீட்டெடுக்கலாம்.
🔒 பாதுகாப்பு PIN (விருப்பம்)
💡 இதை அமைத்தால், "கடன் கணக்கு"-ல் ஒரு வாடிக்கையாளரிடம் இருந்து பணம் பெற்றதை பதிவு செய்யும் முன் இந்த PIN-ஐ கேட்கும் — பணியாளர்கள் தவறாக/தானாக பணம் பெற்றதாக பதிவு செய்வதை தடுக்க. காலியாக விட்டால், வெறும் உறுதிப்படுத்தல் (Confirm) மட்டும் போதும்.

☁️ Auto Cloud Backup
சரிபார்க்கப்படுகிறது...
💡 Sync Code அமைத்திருந்தால், ஒவ்வொரு நாளும் தானாக உங்கள் பொருட்கள்/விற்பனை/கடன் தகவல்கள் Cloud-ல் Backup ஆகும் — நீங்கள் எதுவும் தட்ட வேண்டாம். மொபைல் தொலைந்தாலோ மாறினாலோ, புதிய Device-ல் இதே Sync Code-ஐ இங்கு போட்டு "⬇️ Cloud Restore" தட்டி எல்லாவற்றையும் மீட்டெடுக்கலாம்.
