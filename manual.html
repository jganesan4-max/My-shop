1. அறிமுகம்

கடை பில் (Kadai Bill) என்பது சிறு கடைகளுக்கான எளிய பில்லிங் ஆப். இதை பயன்படுத்த இணையம் (இன்டர்நெட்) தேவையில்லை — கடையில் உள்ள பொருட்களை தட்டி அல்லது குரல் மூலம் சொல்லி பில் போடலாம், பணம் கணக்கிடலாம், ரசீது கொடுக்கலாம்.

இந்த கையேட்டில் ஆப்பின் ஒவ்வொரு பட்டன் மற்றும் அம்சத்தையும் விளக்கமாக பார்க்கலாம்.

2. ஆப்பை திறத்தல் / Home Screen-ல் சேர்த்தல்

ஆப்பை Chrome பிரவுசரில் திறந்தவுடன் மேலே வலது பக்கம் "📱 Home Screen" பட்டன் தெரிந்தால், அதை தட்டி Home Screen-ல் ஆப் ஐகானாக சேர்த்துக் கொள்ளலாம். இதன் பிறகு, மற்ற ஆப்கள் போலவே இந்த ஐகானை தட்டி நேரடியாக ஆப்பை திறக்கலாம்.

💡 இது இணையம் இல்லாமலும் வேலை செய்யும் (Offline). பில் தகவல்கள் உங்கள் மொபைலிலேயே சேமிக்கப்படும்.

3. முதன்மை திரை (Home Screen)

மேல் பகுதி (Header)

  • கடை லோகோ மற்றும் கடை பெயர் — Settings-ல் மாற்றலாம்
  • ⚙️ பட்டன் — பொருட்கள் மற்றும் அமைப்புகளை திருத்த
  • மொத்தம் (₹) — தற்போதைய பில்லின் மொத்த தொகை பெரிதாக காட்டப்படும்
  • எத்தனை வகை பொருட்கள் / மொத்த எண்ணிக்கை

மைக் பட்டன் (🎤)

பெரிய தங்க நிற மைக் பட்டனை தட்டினால், தொடர்ந்து கேட்கும் நிலைக்கு (Listening) செல்லும் — சிவப்பு நிறமாக மாறி துடிக்கும். இந்த நிலையில் நீங்கள் பொருட்களின் பெயர்களை தொடர்ச்சியாக சொல்லலாம்; ஒவ்வொரு முறையும் தானாக பில்லில் சேரும். மீண்டும் தட்டினால் மைக் நிற்கும்.

பொருட்கள் Grid

கடையில் வழக்கமாக விற்கும் பொருட்கள் இங்கே கார்டுகளாக காட்டப்படும். ஒரு கார்டை தட்டினால் அந்த பொருள் 1 எண்ணிக்கையுடன் பில்லில் சேரும்.

பட்டியலில் இல்லாத பொருள் (Quick Add)

  • பொருள் பெயர் — தட்டச்சு செய்யலாம் அல்லது 🎙️ மூலம் பேசி நிரப்பலாம்
  • விலை (₹) — தட்டச்சு செய்யலாம் அல்லது 🎙️ மூலம் சொல்லலாம்
  • எண்ணிக்கை — Default 1; தேவைப்பட்டால் மாற்றலாம்
  • "+ பில்லில் சேர்" தட்டி பில்லில் சேர்க்கவும்
💡 இந்த வழியில் சேர்க்கும் பொருள் நிரந்தரமாக பட்டியலில் சேராது — இந்த பில்லுக்கு மட்டும். நிரந்தரமாக சேர்க்க Settings-ல் "+ பொருள் சேர்" பயன்படுத்தவும்.

4. குரல் மூலம் பில் போடுதல்

மைக் பட்டனை (🎤) தட்டி பேசத் தொடங்கலாம். சில உதாரணங்கள்:

  • "அரிசி இரண்டு" → அரிசி × 2 சேரும்
  • "பால் பாக்கெட் மூன்று, பிஸ்கட் ஐந்து" — ஒரே முறையில் பல பொருட்களையும் சொல்லலாம்
  • பட்டியலில் இல்லாத பொருள் பெயரை சொன்னால், விலை/எண்ணிக்கையுடன் சேர்க்க "பேனா ரூபாய் பத்து" போன்று ஒரு எண் + விலை உடன் சொல்லலாம்

ஒவ்வொரு முறையும் ஆப் சேர்த்த பொருளை குரலில் உறுதிப்படுத்தும் ("அரிசி இரண்டு சேர்க்கப்பட்டது" என பேசும்).

💡 மைக் பேசும் போது ஆப் தானாக மைக்கை நிறுத்தி, பேசி முடித்தவுடன் மீண்டும் கேட்கத் தொடங்கும் — தன் குரலை தானே கேட்டு தவறாக சேர்க்காது.

5. இந்த பில் — திருத்துதல்

திரையின் கீழ் பகுதியில் "இந்த பில்" எனும் பட்டியலில் இதுவரை சேர்க்கப்பட்ட பொருட்கள் காட்டப்படும். ஒவ்வொரு வரிசையிலும்:

  • ✏️ (எடிட்) — எண்ணிக்கையை மாற்ற தட்டவும்; 0 அல்லது காலி விட்டால் அந்த பொருள் நீக்கப்படும்
  • ❌ (நீக்கு) — அந்த பொருளை பில்லிலிருந்து முழுவதுமாக நீக்கும்

6. Standby பில் — பல வாடிக்கையாளர்களை கையாளுதல்

ஒரு வாடிக்கையாளரின் பில் போட்டுக்கொண்டிருக்கும் போதே, இன்னொரு வாடிக்கையாளர் வந்தால், தற்போதைய பில்லை இழக்காமல் புதிய பில் தொடங்கலாம்:

  1. கீழே ⏸️ பட்டனை தட்டவும்
  2. "🍄 புதிய பில்" தட்டவும் — தற்போதைய பில் Standby-ல் பாதுகாப்பாக வைக்கப்படும்
  3. புதிய வாடிக்கையாளருக்கு பில் போடலாம்
  4. முந்தைய வாடிக்கையாளர் பணம் கொடுக்க தயாராக இருந்தால், ⏸️ பட்டனை மீண்டும் தட்டி, அந்த பில்லுக்கு "தொடர்" தட்டவும்
💡 Standby பட்டனில் இருக்கும் சிறிய எண் (Badge) எத்தனை பில்கள் காத்திருக்கின்றன என காட்டும்.

7. பில் முடித்தல்

பொருட்கள் அனைத்தும் சேர்த்த பிறகு கீழே "✅ பில் முடி" பட்டனை தட்டவும். இரண்டு படிகள் நடக்கும்:

படி 1 — பில் சரிபார்க்கவும்

பொருள், விலை, எண்ணிக்கை, தொகை என அட்டவணையாக காட்டப்படும். தவறு இருந்தால் "✏️ திருத்த" தட்டி பின் செல்லலாம். சரி எனில் "பணம் பெறுதல் ➤" தட்டவும்.

படி 2 — குரல் உறுதிப்படுத்தல்

ஆப் முழு பட்டியலையும் (பொருட்கள் + மொத்த தொகை) குரலில் படித்துக் காட்டும், அதே தகவல் திரையிலும் அட்டவணையாக காட்டப்படும். மீண்டும் கேட்க "🔁 மீண்டும் சொல்லவும்" பயன்படுத்தலாம். எல்லாம் சரி எனில் "✅ சரி, தொடரவும்" தட்டி பணம் பெறுதல் திரைக்கு செல்லவும்.

💡 இந்த இரண்டு படி சரிபார்ப்பும், தவறான பொருள்/தொகை பில் ஆகிவிடாமல் தடுக்க உதவும்.

8. பணம் பெறுதல்

மூன்று வழிமுறைகளில் ஒன்றை தேர்வு செய்யலாம்:

💵 பணம் (Cash)

  • பெறப்பட்ட தொகையை தட்டச்சு செய்யலாம், 🎤 மூலம் சொல்லலாம், அல்லது நோட்டு தொகை பட்டன்களை (₹50, ₹100...) தட்டி தேர்வு செய்யலாம்
  • தொகை போட்டவுடன், திரும்ப கொடுக்க வேண்டிய மீதம் (பச்சை நிறத்தில்) அல்லது இன்னும் தேவைப்படும் தொகை (சிவப்பு நிறத்தில்) தானாக காட்டப்படும்
  • "முடிந்தது ✅" தட்டி பில்லை முடிக்கவும் — ஆப் "பில் முடிந்தது" என்றும், மீதம்/தேவை தொகையையும் குரலில் சொல்லும்

🏦 வங்கி / UPI

முழு தொகையும் UPI/வங்கி மூலம் பெறப்பட்டதாக பதிவு செய்யப்படும். "முடிந்தது ✅" தட்டவும்.

📜 வழக்கமான வாடிக்கையாளர் (Credit)

பணம் இன்னும் பெறப்படவில்லை என்றால், வாடிக்கையாளர் பெயரை தட்டச்சு செய்து பதிவு செய்யலாம். இந்த தொகை History-ல் "📜" குறியீட்டுடன் காட்டப்படும்.

9. ரசீது திரை

🔵 நேரடி பிரிண்ட் (Bluetooth) — பரிந்துரைக்கப்படுகிறது

Bluetooth thermal பிரிண்டர் இருந்தால், இதுவே மிக எளிதான வழி — ஒரே தட்டலில் நேரடியாக பிரிண்ட் ஆகும், PDF தேவையில்லை.

  1. "ESC/POS Bluetooth Print Service" ஆப்பை Play Store-ல் இருந்து நிறுவவும்
  2. அதில் உங்கள் Bluetooth பிரிண்டரை (எ.கா. Evolute) இணைத்து, காகித அளவை (2″ / 3″) அமைக்கவும்
  3. கடை பில் ஆப்பில் "🔵 நேரடி பிரிண்ட்" தட்டவும் — Android Share திரை திறக்கும்
  4. அதில் அந்த ஆப்பை தேர்வு செய்யவும் — உடனே பிரிண்ட் ஆகும்

🖨️ PDF பிரிண்ட்

இது பிரவுசரின் இயல்பான Print திரையை திறக்கும் — PDF ஆக சேமிக்கவோ, அல்லது வேறு பிரிண்டர் Service மூலமாகவோ பிரிண்ட் செய்யலாம்.

🔁 மீண்டும்

இதே பில்லை மீண்டும் புதிய பில்லாக ஏற்ற இதை தட்டவும் — அடிக்கடி ஒரே மாதிரி வாங்கும் வாடிக்கையாளர்களுக்கு பயனுள்ளது.

💬 WhatsApp / ✉️ SMS

ரசீதின் விவரங்களை உரையாக (Text) வாடிக்கையாளருக்கு அனுப்பலாம்.

10. இன்றைய விற்பனை (📜 History)

  • ஒவ்வொரு பில்லும் எண், நேரம், பணம் செலுத்திய முறை, தொகை என காட்டப்படும்
  • 🔁 பட்டன் மூலம் அந்த பில்லை மீண்டும் ஏற்றலாம்
  • பணம் வகைவாரியாக (Cash / Bank / Credit) பை சார்ட் காட்டப்படும்
  • "⬇️ Excel-ஆக பதிவிறக்கம்" மூலம் முழு பட்டியலையும் CSV/Excel ஆக பதிவிறக்கம் செய்யலாம்

☁️ எல்லா Device முழு ரிப்போர்ட்

பல மொபைல்/பணியாளர்கள் ஒரே கடைக்கு பில் போட்டால், அனைத்து Device-களின் பில்களையும் ஒன்றாக பார்க்க இதை பயன்படுத்தலாம் (Sync Code அமைத்த பின்).

11. அமைப்புகள் (⚙️ Settings)

கடை பெயர்

கடையின் பெயரை மாற்றலாம் — இது முதன்மை திரையிலும், ரசீதிலும் காட்டப்படும்.

புதிய பொருள் சேர்த்தல்

பொருள் பெயரை தட்டச்சு செய்யலாம் அல்லது 🎤 மூலம் பேசி நிரப்பலாம். "+ பொருள் சேர்" தட்டினால் நிரந்தரமாக Grid-ல் தோன்றும்.

🌐 Sync Code (பல Device ரிப்போர்ட்)

இது பொருட்கள் பட்டியலை இணைக்காது — ரிப்போர்ட்டுக்காக மட்டும்:

  • Sync Code — உங்கள் கடையின் தனித்துவமான குறியீடு. எல்லா Devices-லும் இதே Code-ஐ போடவும்
  • Device / பணியாளர் பெயர் — இந்த மொபைலில் பில் போடும் நபர்/கவுண்டரின் பெயர்

12. Bluetooth Thermal பிரிண்டர் அமைத்தல்

  1. பிரிண்டரை மொபைலுடன் Bluetooth மூலம் Pair செய்யவும்
  2. Play Store-ல் இருந்து "ESC/POS Bluetooth Print Service" ஆப்பை நிறுவவும்
  3. அந்த ஆப்பை திறந்து, பிரிண்டரை தேர்வு செய்து, காகித அகலத்தை (2 inch / 3 inch) அமைக்கவும்
  4. Kadai Bill-ல் ரசீது திரையில் "🔵 நேரடி பிரிண்ட்" தட்டி, Share பட்டியலில் அந்த ஆப்பை தேர்வு செய்யவும்

13. இலவச பயன்பாட்டு காலம் & Activation

ஆப்பை முதன்முறை பயன்படுத்தும் நாளிலிருந்து 30 நாட்கள் இலவசமாக பயன்படுத்தலாம். 30 நாட்களுக்குப் பிறகு, விற்பனையாளரிடம் இருந்து பெறும் Activation Code-ஐ பதிவு செய்து ஆப்பை தொடர்ந்து பயன்படுத்தலாம்.

14. உதவிக்குறிப்புகள்

மைக் வேலை செய்யவில்லை

  • Chrome-ல் மைக் அனுமதி கொடுக்கப்பட்டுள்ளதா என சரிபார்க்கவும்
  • மற்றொரு ஆப் மைக்கை பயன்படுத்திக் கொண்டிருக்கலாம் — அதை மூடிவிட்டு முயற்சிக்கவும்
  • இணைய இணைப்பு (WiFi/Data) தேவை — குரல் அடையாளம் காண இணையம் தேவை

பிரிண்ட் ஆகவில்லை

  • பிரிண்டர் Bluetooth Pair ஆகியுள்ளதா என சரிபார்க்கவும்
  • "ESC/POS Bluetooth Print Service" ஆப்பில் பிரிண்டர் சரியாக தேர்வு செய்யப்பட்டுள்ளதா என பார்க்கவும்
  • பிரிண்ட் சிறிதாக வந்தால், அந்த ஆப்பில் காகித அகலம் (58mm/80mm) சரியாக அமைக்கவும்

☁️ Cloud ரிப்போர்ட் காட்டவில்லை

  • எல்லா Devices-லும் ஒரே Sync Code உள்ளதா என சரிபார்க்கவும்
  • இணைய இணைப்பு தேவை
  • பணியாளர் Device-ல் பில் போட்ட பிறகே அது ரிப்போர்ட்டில் தெரியும்

பொருட்கள் Grid காலியாக உள்ளது
